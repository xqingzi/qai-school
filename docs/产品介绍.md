# QAI 学习助手

## 为什么做这个应用

- 老师建议整理错题本，但手抄太费时间，孩子坚持不下来
- 好不容易整理了一些，到复习时又不知道从哪看起
- 同样的知识点反复错，但混在一堆作业里很难发现规律
- 想帮孩子复习，却不清楚具体哪里没掌握好

这个工具的目的是：把整理错题这件事变得简单，让复习更有针对性。

---

## 设计原则

**1. 中文界面为主**

- 所有 UI 元素使用中文（除非是英语课相关内容）
- 这是给中国小学生使用的工具，语言环境应符合日常习惯

**2. 个人项目定位**

- 当前阶段为个人项目，不需要考虑商业化
- 没有独立的后端服务支持
- 使用 LLM API（如 ZAI、DeepSeek）提供 AI 能力
- 架构设计应保持灵活，随着 LLM 能力的提升，APP 功能上限可以自然增长
- 不要因为当前的设计限制了未来的扩展性

**3. 辅助而非代替**

- 核心定位是**辅助学习和引导学习**
- 不能代替学生思考
- 提示和引导应该是启发式的，而非直接给出答案
- 例如：不要直接告诉"这道题选 A"，而是引导"再读一下题目，看看哪里可能理解错了"

---

## 主要功能

### 拍照收集错题

批改完的作业拍一张照片，应用会自动分析并总结出：

- **知识点**：这道题考查的是什么
- **题目类型**：计算题、应用题、填空题等
- **错误原因**：是粗心还是概念不清
- **薄弱环节**：哪个步骤或理解出了问题
- **思维分析**：解题思路哪里走偏了

这些总结会保存下来，后续复习时可以直接交给 AI 来辅助巩固。

整个过程尽量自动化，减少人工确认和修改的步骤。

### 错题归档整理

错题会自动分类：

- 按科目：数学、语文、英语
- 按知识点：比如「两位数乘法」「分数比较」
- 按时间：可以看这周、这个月的错题
- 按来源：校内练习、家庭作业、自主练习

这样能比较清楚地看到孩子在哪些知识点上出错较多。

### 复习巩固

复习时可以：

- 针对某个知识点生成相似的练习题
- 重新做之前的错题
- 做完后看批改和讲解
- 记录每个知识点的掌握情况

AI 会根据之前总结的错误原因和薄弱环节，有针对性地出题和讲解。

## 怎么用

### 日常录入

错题的来源有几种：

**校内练习**
```
放学带回批改好的练习 → 拍照录入
```

**家庭作业**
```
方式一：完成作业 → 家长批改 → 当场拍照录入
方式二：完成作业 → 第二天老师批改后带回 → 拍照录入
```

**自主练习**
```
自己做练习册或试卷 → 对答案 → 拍照录入错题
```

### 周末复习

```
查看本周错题 → 做相似题练习 → 看哪些掌握了
```

### 考前复习

```
查看错题统计 → 找出薄弱知识点 → 针对性练习
```

## 功能细节

### 拍照识别

| 步骤 | 说明 |
|------|------|
| 拍照 | 对准作业或试卷拍照 |
| 选择来源 | 标记是校内练习、家庭作业还是自主练习 |
| 自动分析 | AI 识别错题并生成总结 |
| 保存 | 自动归档 |

识别结果包括：
- 原题图片
- 题目文字内容
- 知识点标签
- 错误类型和原因分析
- 薄弱环节总结

支持选择题、填空题、计算题、应用题、判断题。

### 错题管理

- 按科目、知识点、时间、来源筛选查看
- 可以搜索特定题目
- 可以添加自己的笔记
- 可以标记"已掌握"或"需重点复习"

### 复习模式

| 模式 | 说明 |
|------|------|
| 知识点巩固 | 针对某个薄弱知识点做专项练习 |
| 错题重做 | 重新做之前的错题 |
| 随机测验 | 混合出题 |

AI 会根据之前记录的错误分析来出题和讲解，不是简单地重复原题。

### 学习统计

- 错题数量变化
- 各知识点掌握程度
- 复习记录

## 一些说明

**关于识别**

使用 AI 视觉模型，目标是尽量自动完成分析和总结，减少人工干预。

**关于数据存储**

数据优先存在 iPad 本地，可以选择是否同步到云端。

**适用年级**

主要面向小学 1-6 年级。

**是否需要联网**

拍照识别和生成练习题需要联网。查看已保存的错题可以离线。

**界面风格**

会做成卡通风格，让小朋友用起来更有兴趣。
